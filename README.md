# 🎮 CATUI
A 《7 Days to Die》 Simple UI.  
![CATUI](https://i.postimg.cc/FRDbR8cr/image.png "CATUI")

## ✨ Feature
- Interface: Redesigned UI for QoL
- Shortcuts: Hold the SHIFT key for priority execution (cutting in line) when crafting, repairing, or disassembling; ALT+LMB on inventory slots to lock/unlock them
- Status data: Including world stage, looting stage, trading bonus, armor level, mobility, running speed, and more
- Zombie health bars: Health bars distinguishing between ferocious and irradiated zombie types, as well as various zombie buffs/debuffs (armor level, bleeding/electrified/burning statuses, etc.)
- Vehicles: Vehicle speedometer, vehicle inventory status, and other related info
- Current weather status and storm countdown
- Blood Moon countdown
- Skill interface
- Merchant interface
- Crafting interface
- Large Toolbelt (optional; customize the number of toolbar slots and switch via ALT+123…0)
- Large Backpack (optional)
- Theoretically supports various UI-free custom overhaul mods, including Ravenharest, War3zuk, ETF, and many more

## 🧩 Optional Mods
- `ZZZ_CATUI_toolbelt_more_slot`: A large toolbelt with 12 slots by default. Switch slots via ALT+123...0. Adjust slot count by modifying numbers in /Config/XUi/windows.xml
- `ZZZ_CATUI_backpack_91slot`: A large backpack with 91 slots
- `ZZZ_CATUI_local_load`: Forces local CATUI mod usage in multiplayer. Resolves continuous errors when other players don't have CATUI installed

## ⚠️ Important Notes
- ✅ Multiplayer: Both server and client need to install this mod, or use the `ZZZ_CATUI_local_load` plugin
- ✅ Single-player: Can be used directly after installing the mod
- ❌ Direct connection: Does not support direct server connection (contains static resources and dynamic link libraries)
- ❌ EAC: Must disable Easy Anti-Cheat
- ‼️ Do not delete the 0_TFP_Harmony folder under the mods directory! If accidentally deleted, restore it by verifying the game's integrity.
